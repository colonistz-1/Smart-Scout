# Outputs

Generated metrics, figures, logs, and predictions belong here.

Results can be regenerated by running the relevant scripts or notebooks.

## Evaluation Metrics

Smart-Scout uses clustering metrics:

- **Silhouette score:** Higher indicates stronger cluster separation.
- **Davies–Bouldin Index:** Lower indicates more compact, separated clusters.
- **Adjusted Rand Index:** Measures agreement between clustering runs.
- **Cluster sizes:** Show how players are distributed across groups.
