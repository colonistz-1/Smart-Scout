# Models

Trained model bundles generated by `scripts/train.py`.

## Selected Model

`kmeans_v2.joblib` contains:

- Fitted K-Means model with **3 clusters**
- Fitted StandardScaler used during training

The model uses six per-90 features:

1. Expected goals
2. Expected assists
3. Tackles
4. Interceptions
5. Key passes
6. Accurate crosses

Training includes **92 Premier League midfielders** with at least
**450 minutes played**, using `random_state=42` and `n_init=10`.

## Results

- Silhouette score: **0.302**
- Davies–Bouldin Index: **1.198**
- Cluster sizes: **19, 51, 22**

The clusters broadly represent creative/delivery-oriented,
defensive-oriented, and goal-threat-oriented statistical profiles.
Cluster numbers are arbitrary and may change after retraining.

## Reproduce

From the repository root:

```bash
python scripts/train.py --config config/config_exp02.yaml
```

The configuration specifies the input dataset and output paths.

## Usage

Load the bundle with `src.model.load_model()`.
Transform player features using the saved scaler before calling
the model or calculating similarity distances.

Do not fit a new scaler during inference. Input features must match
the training feature names and order.

## Version Control

Model artifacts are ignored by default. The selected v2 bundle may
be explicitly tracked for deployment through a `.gitignore` exception.

Only load trusted joblib files; loading them can execute Python code.
